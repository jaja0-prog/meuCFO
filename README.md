# Meu CFO

App de controle financeiro pessoal e empresarial. Um único arquivo HTML,
sem necessidade de build — os dados ficam salvos no navegador de quem acessa.

## Publicar com GitHub Pages

1. Depois de subir este repositório, vá em **Settings → Pages**
2. Em "Branch", selecione `main` (ou `master`) e a pasta `/ (root)`
3. Salve — em alguns minutos o site fica disponível em:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
